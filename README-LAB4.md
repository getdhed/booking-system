# Лабораторная работа №4 — React и localStorage

Клиент находится в папке `client` ветки `24` репозитория `booking-system`.
Серверную часть запускать не требуется: лабораторная автономная.

## Запуск

```bash
git switch 24
cd client
npm install
npm run dev
```

Открыть адрес, показанный Vite (обычно http://localhost:5173).

## Что проверить

1. Добавить помещение и убедиться, что оно появилось в списке.
2. Изменить его и удалить другое помещение (с подтверждением).
3. Найти помещение по названию или номеру, включить фильтр, изменить сортировку.
4. Перезагрузить страницу: сохранённые изменения должны остаться.
5. Открыть DevTools → Application → Local Storage: данные находятся по ключу `booking-system-rooms`.
6. Убедиться, что количество помещений отражается в заголовке вкладки.

Для проверки сборки: `npm run build`.

## Основные файлы

- `src/App.jsx` — состояние, добавление, изменение, удаление, поиск и сортировка.
- `src/components/RoomForm.jsx` — форма помещения.
- `src/components/RoomList.jsx` — список карточек.
- `src/hooks/useLocalStorage.js` — загрузка данных при монтировании и сохранение при изменениях.

Это только клиентская лабораторная: запросов к REST API и PostgreSQL пока нет.
